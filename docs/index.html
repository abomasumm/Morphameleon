How it works

Proof comes before the edit

Protect
GLM-5.3 Flash writes tests for what the old code does today, odd results included. Source stays untouched.
Convert
DeepSeek V4.1 Flash and MiniMax M3.1 Flash compete on every migrate task. Neither can edit the tests.
Review
NVIDIA Nemotron 3.5 Super VL judges and reviews every change, a family no worker uses. All of it runs on Nebius Token Factory.
Merge
Passing work lands on a separate branch. Only a person merges it into main.
